\section{Discussion and Conclusion}\label{sec:scope}\label{sec:conclusion}
Retained matrix products and arbitrary paid history can coexist with
acceptance bounds under a fresh-work budget. Conditioning on rank
strengthens agreement at positive work budgets, and a resource recursion
composes the per-round bounds under adaptive pathwise spending, including
rounds that accept an already incorrect reference. Checking allocation
then turns an acceptance target into a finite resource decision, kept
separate from the integrity budget that governs output correctness. Exact-field
measurements locate the scale at which arithmetic reuse outweighs
candidate materialization, and fresh randomized attribute reports connect
encoding, statistical accuracy, and verification cost. These guarantees
hold for the stated causal ordering and bilinear program class. The
prototype exercises that interface through trusted kernel admission;
accounting for the same work under untrusted general-purpose execution
would require a separate enforcement mechanism.
